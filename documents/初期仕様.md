# 個人活動ログ自動集計・活用システム 仕様書

# 1. システム目的

本システムは、ユーザーのWindows環境における全活動を記録・蓄積し、「ユーザーの外部記憶・自己理解を助けるAI秘書」を構築することを目的とする。

「先週のあの時、何を考えてこれを作っていた？」「最近の自分の集中パターンは？」といった、ユーザー自身の過去や傾向に関する問いに対し、蓄積された膨大なログ（コンテキスト）に基づき、的確な回答や示唆を提供する。

# 2. システム構成

大きく分けて4つのサブシステムからなる

## 1. ロガーシステム

ユーザーの行動をロギングするツール群

ツールとして、osapiからデータ取得するツール、chromeのデータを取得するchrome拡張ツール、chrome以外のアプリについて定期的にSSを取りデータ取得をするツールを持つ（将来的に追加可能な設計とする）

各ツールは独立したシステムとして存在する

取得したデータはデータ蓄積システムに送る。

## 2. データ蓄積システム

ロガーから送られてきたデータを、処理、蓄積する

AWSのIoTCore,Glue,DynamoDB,S3,Bedrock,Lambda等を活用し、蓄積、RAG化

送られてくるさまざまな情報（SSやHTML）などの情報はBedrockを活用し、データを抽出し、共通形式に変換のち、蓄積する

## 3.1 日誌作成システム

データ蓄積システムに蓄積されたデータをもとに、その日の日報を作成する

日報の作成はEventBridge、Lambdaを用いて定期的に実行し、Notionと連携し自動的にNotionのページに追加していく

（web管理画面あり）

## 3.2 自分のデジタルツインシステム

データ蓄積システムに蓄積されたデータをもとに自分の過去の行いなどを質問できるチャットbot

自分の思考や性質などを聞ける

# 3. 開発フロー

個人活動ログ自動集計・活用システムの開発ではAI-DLC（https://github.com/awslabs/aidlc-workflows）を活用する

個人活動ログ自動集計・活用システム全体を1つの親AI-DLCと複数の子AI-DLCを組み合わせて開発する。

親AI-DLCは子AI-DLCの開発に必要な情報を作成し、子AI-DLCの入力として活用する

```text
親AI-DLC　個人活動ログ自動集計・活用システム
　子AI-DLC　ロガーシステム
　　孫AI-DLC　osapiからデータ取得するツール
　　孫AI-DLC　chromeのデータを取得するchrome拡張ツール
　　孫AI-DLC　chrome以外のアプリについて定期的にSSを取りデータ取得をするツール
　子AI-DLC　データ蓄積システム
　子AI-DLC　日誌作成システム
　子AI-DLC　自分のデジタルツインシステム
```

という構成とし、各AI-DLCが個別のワークスペースを持ち、独立に開発を進めることを可能にする
