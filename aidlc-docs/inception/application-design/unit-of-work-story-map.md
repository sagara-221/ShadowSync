# ユニットマッピング (Story Map)

ユーザーストーリー（高レベル要件）と担当ユニットの紐付けです。

1. **PC上の様々なログを漏れなく収集したい**
   * 担当: `logger/osapi/`, `logger/chrome-extension/`, `logger/ss-tool/`
2. **収集したデータ（画像・HTML等）を意味のある共通フォーマットに整形・保存したい**
   * 担当: `data-accumulation/`
3. **毎日の行動をNotionで自動的に日報として振り返りたい**
   * 担当: `daily-log/`
4. **「先週何を考えていたか？」など、自分の傾向についてAIに質問したい**
   * 担当: `digital-twin/`
