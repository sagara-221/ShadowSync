# 開発インテント (スクリーンショット取得 ロガーツール)

**目的**: Chrome以外のアプリ使用時など、画面の視覚的情報を定期的にスクリーンショット(SS)として取得し、AWSバックエンドへ送信するツールの開発。

**要件**:
- 独立したアプリケーションとして動作すること。
- **データ送信の制約**: IoT Coreのペイロード上限（128KB）を回避するため、SS画像自体は直接S3へアップロード（Presigned URL等を利用）し、そのメタデータ（S3パス等）のみをMQTT（X.509証明書認証）でIoT Coreへ送信するアーキテクチャとすること。
- 撮影頻度や保存/送信の最適化（ローカルでの一時保存など）については本AI-DLCにて最適設計を行うこと。
- インターフェースの詳細は、親AI-DLCで定義した `../../aidlc-docs/inception/application-design/data-accumulation-interface.md` を必ず参照・準拠すること。
