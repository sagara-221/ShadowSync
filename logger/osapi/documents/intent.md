# 開発インテント (OS API ロガーツール)

**目的**: ローカルWindows PCのOS APIを監視し、アクティビティ情報（ウィンドウ切り替え、キー入力・マウスクリックなどのアクティビティ有無等）を取得し、AWSバックエンド（IoT Core/MQTT想定）へ送信するツールの開発。

**要件**:
- 独立したアプリケーションとして動作すること。
- 送信先（AWS IoT Core等）の認証設定やペイロードフォーマットについては、独立して決定・設計するか、データ蓄積システム側の仕様に準拠すること。
- データの取得頻度やトリガー条件（定期取得か、イベントドリブンか）については本AI-DLCにて最適設計を行うこと。
